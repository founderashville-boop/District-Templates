# ServerVault

A Xenon-inspired Discord server template gallery frontend.

## Included
- Responsive template gallery
- Search
- Category filters
- Sorting
- Template cards
- Template submission modal
- LocalStorage persistence for submitted templates
- Responsive mobile layout
- Ready to connect to a real backend and Discord OAuth

## Run
Open index.html in a browser.

## Production backend
For a real public service, connect:
1. Discord OAuth2 for accounts
2. Database for templates/users/votes
3. Moderation/admin dashboard
4. Discord template URL validation
5. API endpoint for submissions
6. Hosting such as Cloudflare Pages, Vercel, Netlify, or GitHub Pages

This is an original implementation inspired by the general template-gallery concept, not a copy of Xenon's source code or branding.
